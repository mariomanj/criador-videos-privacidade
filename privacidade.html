Política de Privacidade — Criador de Vídeos (ferramenta interna)

Última atualização: 18 de novembro de 2026

O que é este app

O "Criador de Vídeos" é uma ferramenta de uso pessoal e interno, usada apenas pelo dono dos canais VAR da Resenha, Arquivo Oculto, Se Fosse Você e E se.. Pixel para gerenciar os próprios canais no YouTube. O app não é oferecido ao público.

Quais dados o app acessa

Com a autorização do dono da conta, pelo login do Google (OAuth), o app usa a API de Dados do YouTube para:

  • enviar vídeos, thumbnails e legendas aos canais do próprio dono;
  • editar título, descrição, tags e playlists desses vídeos;
  • ler estatísticas e métricas desses canais.

O app não acessa canais, vídeos ou dados de outras pessoas.

Como os dados são guardados

O acesso autorizado (token) fica salvo só no computador do dono dos canais. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions.

Uso dos serviços do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, valem os Termos de Serviço do YouTube (https://www.youtube.com/t/terms) e a Política de Privacidade do Google (https://policies.google.com/privacy).
